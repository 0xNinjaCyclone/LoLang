## LoLang Sample Suite

- **01-05**  literals, variables, arithmetic, comparisons, logical/bitwise operations
- **06-10**  compound assignment, increment/decrement, lists, maps, members/calls
- **11-16**  imports/needs, conditionals, nesting, while, for, break/continue
- **17-20**  functions, recursion, Fibonacci, GCD
- **21-27**  searching, sorting, prefix sums, number theory, sieve
- **28-30**  expression stress, checksum, multi-function real-world pipeline

The suite is intentionally progressive. Later samples combine features introduced earlier.
